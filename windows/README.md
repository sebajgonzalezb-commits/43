# 43 para Windows (opcional)
1. En tu PC Windows instala Node.js.
2. Abre una terminal dentro de esta carpeta `windows`.
3. Ejecuta `npm install` y luego `npm start` para probar.
4. Al abrir, pega **tu enlace de 43 publicado en Render**. Se guarda localmente.
5. Para generar el instalador ejecuta `npm run dist`: el instalador estará en `windows/dist`.
La aplicación usa el servidor de Render y necesita internet. **Nota:** compartir pantalla desde Electron puede necesitar integración adicional según Windows / Electron. Mientras tanto, usa Chrome o Edge para compartir pantalla.
